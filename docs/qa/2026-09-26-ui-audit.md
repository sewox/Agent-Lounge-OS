## 4. Focus deep dives

### 4a. Experiences (tecrübe)

**Storage**

- SQLite: `experiences/lounge.sqlite` via `default_db_path` (`src-tauri/src/db/experiences.rs`).
- Schema columns: `id`, `project_id`, `agent_id`, `topic`, `solution_summary`, `adr_record`, `outcome`, `related_task_id`, `tags_json`, `created_at`, `embedding`, `payload_json`.
- Wire type `LoungeExperience` flattens ADR → `adr_summary`.
- Optional remote vector upsert: `vector_memory` collection `lounge-experiences`.
- MCP: `lounge_record_experience` / `lounge_record_decision` (insert), `lounge_search_experience` (search).
- NATS: `lounge.experience.reported` on record.

**UI today**

- Vault / dashboard Experience Log: time, outcome badge, `project_id`, **clamped** ADR.
- No agent/tags/related_task display.
- Whisper rows: **Faydalı** → `record_whisper_feedback` only (positive).
- Palette search → vault focus (still clamped).
- Provider refresh: `list_experiences` **limit 12**.

**CRUD matrix**

| Action | Store | Tauri cmd | MCP | UI |
|--------|-------|-----------|-----|-----|
| Create | `insert*` | **missing** (kernel/MCP only) | `lounge_record_*` | missing |
| Read list/search | `latest` / `search_experiences` | `list_experiences`, `search_experiences` | search | partial |
| Read by id | `get` | **missing** | — | missing |
| Update | **missing** | missing | missing | missing |
| Delete | `delete_record` (internal) | **missing** | missing | missing |
| Pin / retag / scope / mark wrong | **not in schema** | missing | missing | missing |

**Proposals (for later planning — not implemented here)**

1. **P0** Experience detail drawer: full ADR, agent, tags, topic, related task; expand from card click.
2. **P0** Tauri (+ MCP): `update_experience`, `delete_experience`; UI edit/delete with confirm.
3. **P1** `mark_experience_wrong` / feedback kinds beyond whisper_useful.
4. **P1** Pin + retag + change `project_id` (schema columns or tags convention).
5. **P2** Raise/remove list limit; infinite scroll; show total count.

### 4b. Dead Symbols

**Source**

```
index_workspace → MemoryBridge (CLI tools get_dead_symbols|dead_symbols)
  → persist project_index (kind dead|broken)
UI: get_dead_symbols → ExperienceStore.list_dead_symbols (SQLite)
  fallback: semanticMap.projects[].dead
Browser: mockDeadSymbols after Index, else KPI uses MOCK_HEALTH sum
```

**Model fields** (`DeadSymbol`): `name`, `kind` (`unused`|`broken`), `file`, `line`, `detail`, `project_id`.  
**Not in model:** confidence, last reference.

**UI today:** selection-scoped list ≤8; name + detail/path + kind badge; Health shows aggregate counts only. Rows are non-interactive `<div>`s.

**Feasible actions (all missing)**

| Action | Feasibility | Notes |
|--------|-------------|-------|
| Open in editor | High | `file`+`line` exist; need OS/editor bridge |
| Copy path | High | Clipboard |
| Ignore / whitelist | Medium | Needs persistence table + filter |
| Mark as used / false positive | Medium | Same |
| Create cleanup task for agent | High | Reuse `LoungeTask` + NATS `lounge.task.requested` |
| Show all / export | High | UI pagination |

**Proposals**

1. **P0** Detail panel: all fields + actions toolbar.
2. **P0** Clickable rows; copy path; open file (Tauri plugin).
3. **P1** Whitelist store + “Ignore”; create agent cleanup task.
4. **P1** Align KPI with real `deadSymbols` (never fall back to MOCK_HEALTH when claiming live).
5. **P2** Extend model with confidence / last_ref if MCP provides them.
