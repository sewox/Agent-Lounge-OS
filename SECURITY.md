# Güvenlik Politikası / Security Policy

## Desteklenen sürümler / Supported versions

Güvenlik düzeltmeleri yalnızca [`main`](https://github.com/sewox/Agent-Lounge-OS/tree/main) dalındaki en güncel sürüm için yapılır.
Security fixes are applied to the latest version on [`main`](https://github.com/sewox/Agent-Lounge-OS/tree/main) only.

## Açık bildirme / Reporting a vulnerability

Lütfen güvenlik açıklarını **herkese açık issue olarak açmayın**. Bunun yerine GitHub'ın gizli bildirim formunu kullanın:

Please **do not open public issues** for security vulnerabilities. Use GitHub's private reporting form instead:

👉 https://github.com/sewox/Agent-Lounge-OS/security/advisories/new

Bildiriminize şunları ekleyin / Please include:

- Etkilenen sürüm/commit ve işletim sistemi / Affected version/commit and OS
- Açığın açıklaması ve olası etkisi / Description and potential impact
- Tekrar üretme adımları veya kavram kanıtı / Steps to reproduce or a proof of concept

Bildirimlere en kısa sürede dönüş yapılır; düzeltme yayınlanana kadar ayrıntıların gizli tutulmasını rica ederiz.
Reports are acknowledged as soon as possible; please keep details private until a fix is released.
